# 🎮 Projekt Saper (Minesweeper)

Klasyczna, jednoosobowa gra logiczna "Saper" zaimplementowana jako aplikacja konsolowa w języku C#. Projekt został zmigrowany, zdebugowany i w pełni zabezpieczony przy użyciu systemu kontroli wersji Git.

## 🚀 Jak uruchomić projekt

1. **Sklonuj repozytorium** na swój dysk lokalny.
2. Otwórz plik rozwiązania (`.sln`) lub katalog projektu w środowisku **Visual Studio**.
3. Upewnij się, że wszystkie błędy składniowe zostały naprawione zgodnie z rejestrem Issues.
4. Kliknij zielony przycisk **Uruchom (Play / Start)** na górnym pasku Visual Studio.
5. Gra uruchomi się automatycznie w oknie konsoli systemowej.
